VELOUR — Luxury Car Website

Extract this ZIP, then open index.html in a modern browser.
Keep the frames folder next to index.html, style.css and app.js.

For hosting, upload these files and the frames folder to any static web host.
No build step or dependencies are required.

Includes all 192 optimized WebP animation frames.
Scroll down and up to control the hero animation.
Reduced-motion settings display a still image.
